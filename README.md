💼 Freelancer Bidding Platform
📌 Project Description

This is a Freelancer Bidding Platform built using Python Django, HTML, CSS, and Bootstrap.
The platform allows clients to post projects and freelancers to bid on them. It provides a simple and user-friendly interface for managing freelance work and communication.

🚀 Features
👤 User Authentication (Register / Login / Logout)
📝 Clients can post projects
💰 Freelancers can place bids on projects
📊 View all available projects
📬 Manage bids and project details
🎨 Responsive UI using Bootstrap
🔒 Secure backend using Django
🛠️ Tech Stack
Frontend: HTML, CSS, Bootstrap
Backend: Python (Django Framework)
